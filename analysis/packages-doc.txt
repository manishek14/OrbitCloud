۱۰. موارد خارج از مبلغ ثابت پکیج
•  خرید یا تمدید Licenseهای Microsoft، Antivirus/EDR، Firewall، Backup، نرم‌افزار مالی، VoIP Trunk، SSL تجاری و سایر سرویس‌های ثالث.
•  خرید، تعمیر یا تعویض Hardware، UPS، Server، Storage، Disk، Switch، Router، Access Point و تجهیزات کاربر.
•  اینترنت، IP Static، MPLS، خطوط تلفن/SIP و هزینه اپراتورها.
•  کابل‌کشی Passive، رک، برق، فیبر، دوربین، کنترل تردد و پروژه‌های فیزیکی مگر با قرارداد جداگانه.
•  Migrationهای بزرگ، راه‌اندازی از صفر چندین Server، طراحی مجدد Core Network، Domain Migration، پروژه دیتاسنتر و DR Site.
•  Penetration Test، SOC/SIEM Managed، Forensics و Incident Response گسترده؛ به‌صورت Add-on یا قرارداد مستقل.
•  فضای Cloud و Backup مازاد بر سهمیه هر پکیج و ترافیک/منابع فراتر از مشخصات VPSهای شامل پکیج.
•  حضور در محل خارج از سهمیه پکیج، مأموریت خارج مشهد و هزینه رفت‌وآمد/اقامت.
۱۱. توصیه فروش و جایگاه پکیج‌ها
•  پایه: ورودی کم‌ریسک برای شرکت‌های بسیار کوچک؛ عمداً محدود و اقتصادی.
•  استاندارد: مناسب شرکت‌هایی که AD، File Sharing و یک Server مرکزی دارند.
•  حرفه‌ای: پکیج پیشنهادی AbrIT و بهترین تعادل قیمت/ارزش برای اکثر SMEها.
•  سازمانی: برای سازمان‌هایی با چند Server، چند Site و نیاز به حضور دوره‌ای.
•  سازمانی پلاس: برای زیرساخت حساس، چندسایتی و نیازمند واکنش اضطراری 24×7.
•  Enterprise Custom: بالاتر از ۴۰ User، ۶۰ Endpoint یا ۵ Site؛ قیمت پس از Assessment اولیه.
پیشنهاد قراردادی: تعداد User، Endpoint، Server/VM، Site و تجهیزات مدیریتی در ابتدای قرارداد Inventory و در پیوست قرارداد ثبت شود تا افزایش ظرفیت به‌صورت خودکار مشمول Add-on گردد.
